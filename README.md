# 信息整理工具（Mac）

把视频链接或音频整理成能离线阅读、搜索的图文报告，也能润色、总结或下载视频。

## 日常怎么用

双击 **`start_app.command`**，然后：

1. 粘贴视频链接，或通过“添加…”选择音频、文件夹、链接清单。可以一次添加多条。
2. 第一次使用选 **“只提取原文”**，保持“结合画面”关闭，不用设置文字模型。
3. 点击“开始处理”，完成后点 **“查看结果”**。

新用户默认生成 **`阅读报告.html`，保存到桌面**。它会在浏览器中打开，无需上传网站。保存位置可以直接更改；需要可编辑文稿时勾选 Word，需要 Markdown 时也可勾选。

更新前已经选过 Word 或 Markdown 的，会保留原选择并增加阅读报告；不需要的格式可以取消，之后会记住。

支持 YouTube、哔哩哔哩、抖音、西瓜视频和 Vimeo，也支持本机音频文件、音频文件夹和 `.txt` 链接清单。想保存视频，切到“下载视频”即可。

## 需要润色或总结时

在“选择结果”里选原文加总结、原文加润色稿，或全部内容；都会保留原文。

首次打开 **“设置 → 模型设置”**，填写服务提供的接口地址、模型名称和 API 密钥，再点“测试生成”。点“保存”后记住，点“取消”放弃本次修改。在线处理会发送文字，可能收费；也可选本机 Ollama。

平时不用调整“语音识别”和“网站访问”里的参数。

## PPT、图表或操作画面也重要时

打开 **“结合画面”**，并在“设置 → 模型设置”选择支持图片的模型。目前支持视频链接，音频文件不使用此功能。

工具会先看代表画面，再整理画面笔记；选了总结时，阅读报告会先讲核心判断，再按主题把观点、对应截图和解释串成一篇 **图文讲解**。正文只放帮助理解的图片，其他核对细节收起保留。主要内容已经清楚就结束，只有发现关键缺口才补看，不凑截图数量，也不固定返工轮数。看不清的地方会注明，不会当作原话写进原文稿。

看完觉得某处不够细，可以在画面开关下面的 **重点说明** 填写“把 05:20 附近的图表讲细一点”，再次处理同一链接。有效进度会复用，新结果另存，旧稿保留。

开启后需要下载视频，处理会更慢；在线模型还会接收截图，可能增加费用。“测试生成”只测试文字，能生成文字不代表模型支持图片。

## 怎么阅读、结果在哪里

点 **“查看结果”**，或双击结果文件夹里的 **`阅读报告.html`**：

- 总结和画面一起选择时，直接阅读图文讲解；点击图片下的“查看画面核对说明”可看详细依据。其他情况按所选内容展示，只提取原文时直接展示原文。
- 用目录跳到相关主题、润色稿或原文。旧总结没有明确配图位置时，按时间展示截图及解读，原有文字总结收起保留供核对。
- 在顶部搜索，或按 `⌘F`，可以查找全文；命中折叠内容时会自动展开。用箭头或回车查找下一处。
- 点击截图放大，按 `Esc` 关闭。
- 点“打印 / 保存 PDF”，在浏览器打印窗口选择另存为 PDF。

报告的文字和截图都在文件里，断网也能阅读，单独复制这份 HTML 即可。报告只展示已经处理的内容，不会为展示再次调用模型。

每条内容单独放在一个“标题 + 时间”的文件夹里，默认在桌面，也能点 **“最近结果”**找回。

开启“结合画面”后，报告会包含画面笔记，原始截图另存在 **`images/`**。选择 Word 或 Markdown 时，也会生成对应文稿和画面笔记。Word 已嵌入图片；Markdown 请连同整个结果文件夹保存或移动。

窗口中的“打开文件夹”可以找到全部文件。“最近结果”也能打开过去的内容；旧结果没有阅读报告时，会打开已有文档。下载视频时，“查看结果”直接打开视频。

一项失败不影响其他项。查看原因并修好后，点 **“继续未完成”**；已保存的文字、画面解读和完整下载会复用，中途停止的语音识别或未完成下载需要重新执行。“部分完成”表示仍有内容缺失，请查看文件中的处理提示。

## 让 Codex 直接使用

直接告诉 Codex：**“用这个项目提取这个视频的原文，保存到桌面。”**

它可以直接调用，无需操作窗口。调用说明放在 [AGENTS.md](AGENTS.md)，你不用记命令。

## 打不开或处理失败时

- 首次启动需要联网准备组件。缺少 Python 时，按启动窗口提示安装；更新项目后，组件有变化也会自动准备。
- YouTube 需要 Deno，或在“设置 → 网站访问”中选择已安装的 Node.js。
- 处理失败先看“运行记录”。需要网站登录时，可在“设置 → 网站访问”选择有效的 `cookies.txt`。
- 不知道怎么处理，把错误提示告诉 Codex 即可。

## 以后看哪里、改哪里

主要看这份 **README**，使用时只需打开 **`start_app.command`**。选项直接在软件里改，不用修改代码或记行号。

需要改功能时交给 Codex：入口是 `info_summary/__main__.py`，默认设置在 `info_summary/settings.py`，阅读报告在 `info_summary/html_report.py`，报告外观在 `info_summary/report_assets/`。不用自己查行号或改代码。

## 不要上传到 GitHub

- `.venv/`、`temp/`、`data/`：本机环境、临时文件和个人资料。
- API 密钥、`cookies.txt`、`.env` 文件：服务凭证和网站登录信息。
- 生成的阅读报告、文稿、截图、音频、视频和压缩包。结果建议保存在桌面或项目文件夹外。
- 本机 `~/Library/Application Support/InfoSummary/`：设置、历史记录和续做进度。

常见临时文件已由 `.gitignore` 忽略；个人生成结果上传前仍需确认没有选中。
